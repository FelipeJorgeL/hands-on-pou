# 🌍 Explorando Nossos Sonhos

Projeto desenvolvido para apresentar **lugares do mundo que cada integrante do grupo gostaria de conhecer**.  
O site reúne destinos turísticos escolhidos pelos participantes e direciona para páginas individuais com mais informações sobre cada local.

---

# 📌 Descrição

O projeto **Explorando Nossos Sonhos** é uma página web que exibe uma galeria de destinos turísticos desejados pelos integrantes do grupo. Cada destino possui um card com imagem, nome do lugar e um link que leva para uma página individual criada pelo integrante responsável.

A proposta é explorar conceitos de **desenvolvimento web, organização de layout e navegação entre páginas**.

---

# 🎯 Objetivos do Projeto

- Praticar desenvolvimento web utilizando **HTML e CSS**
- Criar **layouts modernos e responsivos**
- Trabalhar com **estrutura de pastas e organização de arquivos**
- Desenvolver páginas individuais dentro de um mesmo projeto
- Praticar **trabalho em equipe**

---

# 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- Google Fonts  
- Material Symbols (Google Icons)
